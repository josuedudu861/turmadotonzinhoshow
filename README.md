TURMA DO TONZINHO — SITE COMPLETO PARA GITHUB

1. Baixe todos os ZIPs numerados e descompacte cada um.
2. Abra o repositório siterturmadotonzinho no GitHub.
3. Em Add file > Upload files, envie os arquivos DE DENTRO da primeira parte para a raiz, junto ao index.html existente. Confirme em Commit changes.
4. Repita para TODAS as partes. Todos os arquivos devem ficar na mesma pasta do index.html, sem pastas chamadas parte-1, parte-2 etc.
5. Substitua arquivos antigos com os mesmos nomes. Não envie os ZIPs.
6. Depois de enviar todas as partes, aguarde a publicação e recarregue o site.

Este conjunto inclui o site completo, fotos, vídeos, duas cartilhas, o livro O Meu Quarto e imagens para leitura no navegador. PDFs otimizados para uso digital. Originais preservados fora do pacote.
A logo do rodapé já está centralizada nesta versão. Arquivos de versões anteriores podem continuar visíveis até a publicação e atualização do navegador.
